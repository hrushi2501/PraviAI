# Reviewer journeys

## A — Department setup

Authority administrator proposes department → different governance approver approves → manager invites verified member → expert drafts asset definition → adds typed fields, inspection components and allowed lifecycle stages/transitions → submits → independent template reviewer publishes. No active access or template change occurs merely on proposal.

## B — Asset lifecycle

Officer selects published definition → enters core identity/location/provenance and dynamic attributes → saves draft → supplies registration evidence and submits → different verifier verifies → operates in configured lifecycle → complaint prompts investigation → assessor submits component inspection with evidence → independent reviewer approves → responsible officer proposes restoration with sourced estimate → senior approves → assigned executor starts and submits completion → independent senior accepts → assessor submits reassessment → independent approval establishes new condition.

## C — Regional management

Central planner opens dashboard → selects authorised scope → compares current condition with inspection coverage → opens at-risk building → reads dated findings, complaint and work history → reviews priced and unpriced backlog → delegates action through authorised department workflow. Trend claims require comparable approved paired observations, not counts from different inventory snapshots.
